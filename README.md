# go.naywee.com

Go vanity import paths for naywee's modules, served by GitHub Pages at https://go.naywee.com.
Each folder holds one `index.html` with Go's `go-import` and `go-source` meta tags pointing at the module's repository in github.com/nayweelabs. A new module, or a new shared major (`/vN`), adds a folder.
